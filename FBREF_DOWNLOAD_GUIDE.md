# FBref CSV Download Guide

This guide tells you exactly which pages to visit and what to save each file as.
All CSV files go in `data/fbref/` (create that folder first).

## How to export a CSV from FBref

1. Open the URL in your browser
2. Scroll down to the stats table
3. Above the table, click **"Share & Export"** → **"Get table as CSV"**
4. A text box appears — **Select All**, **Copy**
5. Paste into a new file, save with the exact filename shown below

## Part 2 — National Team Stats (WC 2026 Qualifying + Recent Tournaments)

These give us the "last 20 NT matches" equivalent per player.

> **Note:** If a URL gives a 404, search FBref for the competition name
> (e.g. "UEFA World Cup Qualifying 2026") and download from there.

| File name | What to download | FBref search term |
|---|---|---|
| `nt_UEFA_WC.csv` | UEFA WC 2026 Qualifying — Player Standard Stats | "UEFA World Cup Qualifying 2026" |
| `nt_CONMEBOL_WC.csv` | CONMEBOL WC 2026 Qualifying — Player Standard Stats | "CONMEBOL World Cup Qualifying 2026" |
| `nt_CAF_WC.csv` | CAF WC 2026 Qualifying — Player Standard Stats | "CAF World Cup Qualifying 2026" |
| `nt_CONCACAF_WC.csv` | CONCACAF WC 2026 Qualifying — Player Standard Stats | "CONCACAF World Cup Qualifying 2026" |
| `nt_AFC_WC.csv` | AFC WC 2026 Qualifying — Player Standard Stats | "AFC World Cup Qualifying 2026" |
| `nt_AFCON2025.csv` | AFCON 2025 — Player Standard Stats | "Africa Cup of Nations 2025" |
| `nt_CopaAmerica2024.csv` | Copa América 2024 — Player Standard Stats | "Copa América 2024" |
| `nt_UEFANationsLeague.csv` | UEFA Nations League 2024-25 — Player Standard Stats | "UEFA Nations League 2024-25" |

For NT files, download only the **Standard Stats** table (no separate shooting needed — 1 file per competition).

## After downloading

Run from the repo root:
```bash
pip install pandas lxml
python scripts/build_stats_from_fbref.py
```

Add `--dry-run` first to preview without writing files:
```bash
python scripts/build_stats_from_fbref.py --dry-run
```

Then commit and push:
```bash
git add data/manual_stats.json data/manual_nt_stats.json
git commit -m "Update stats from FBref 2025/26 CSVs"
git push
```
